# 📝 Todo With Firebase App

A sleek, modern, and efficient Todo application built using **Flutter** and powered by **Firebase** 🔥. This app helps users manage their daily tasks seamlessly with real-time database updates.

---

## ✨ Features

* 🔐 **Firebase Authentication** – Secure user login and signup flow.
* ⚡ **Real-time Database** – Instant sync across devices using Firebase Firestore/Realtime Database.
* ➕ **Task Management** – Easily Add, Update, and Delete tasks on the go.
* 🎯 **Status Tracking** – Mark tasks as completed or pending.
* 🎨 **Clean UI/UX** – Beautiful, minimalist, and user-friendly interface.
